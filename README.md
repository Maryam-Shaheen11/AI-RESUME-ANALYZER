# 📄 AI Resume Analyzer

## 📌 Problem

Job seekers often apply for jobs without knowing how well their resume matches the job requirements. Manually comparing a resume with a job description is time-consuming and it can be difficult to identify missing skills, keywords, and ATS-related issues.

## 💡 Solution

AI Resume Analyzer is an AI-powered application that compares a user's resume with a specific job description.

The user uploads their resume and enters the job description. The system uses AI to analyze both and provides a **match score, matching skills, missing skills, keywords, ATS issues, and improvement suggestions**.

This helps users understand how suitable their resume is for a particular job and how they can improve it.

## 🛠️ Technologies Used

- **Python** – Application development
- **Streamlit** – Web application interface
- **Groq API** – AI/LLM integration
- **GPT-OSS 120B** – Resume analysis and report generation
- **PyPDF** – PDF resume text extraction
- **python-docx** – DOCX resume text extraction
- **Git & GitHub** – Version control and project hosting

## ⚙️ How It Works

1. **Upload Resume**  
   The user uploads their resume.

2. **Enter Job Description**  
   The user provides the job description they want to apply for.

3. **Text Extraction**  
   The application extracts text from the uploaded resume.

4. **AI Analysis**  
   The resume and job description are analyzed using the AI model.

5. **Generate Results**  
   The system provides a match score, skills analysis, ATS issues, and improvement suggestions.

## 🎯 Objective

The main objective of this project is to help job seekers **quickly understand how well their resume matches a job and identify areas for improvement before applying.**
